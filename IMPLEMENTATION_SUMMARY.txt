SESSION MANAGEMENT FEATURE IMPLEMENTATION SUMMARY
=================================================

FEATURES IMPLEMENTED:

1. AUTO-GENERATED SESSION TITLES
   - Extracts first 3-4 words from user's first message
   - Removes file attachments (@file syntax) from title
   - Cleans whitespace and formatting
   - Fallback to "Quick chat" for very short prompts
   - Manual labels via /new [label] still work and are preserved

2. CENTRALIZED SESSION STORAGE
   - Changed default from: tmp/mtp_tui_sessions (per-directory)
   - Changed to: ~/.mtp/sessions/ (centralized)
   - All sessions from all directories stored in one place
   - Sessions persist even if project directories are deleted

3. DIRECTORY-BASED GROUPING
   - Sessions grouped by working directory when listed
   - Current directory sessions shown FIRST (highlighted with ●)
   - Other directories shown below (marked with ○)
   - Easy to see which sessions belong to which project
   - Up to 20 sessions shown total (8 per directory max)

CODE CHANGES:

1. src/mtp/cli/tui.py
   - Added _generate_session_title_from_prompt() function (line ~522)
   - Added auto-titling logic in main loop after _record_turn (line ~3553)
   - Rewrote _print_saved_sessions() to group by directory (line ~2154)

2. src/mtp/cli/main.py
   - Changed --session-db default to Path.home() / ".mtp" / "sessions" (line ~207)
   - Updated help text to mention centralized storage

BACKWARD COMPATIBILITY:

- Existing sessions without titles show "(unnamed)" as before
- Manual labels via /new [label] continue to work
- Old session databases can be migrated by copying to new location
- All existing functionality preserved
